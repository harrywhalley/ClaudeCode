## Printing Instructions

### Quick Print Method (Fastest):

1. **Open each markdown file** in a text editor or markdown viewer
2. **Copy the card section** (the ASCII art boxes)
3. **Paste into a document** (Google Docs, Word, or text editor)
4. **Print at 100% scale** (do not shrink to fit)
5. **Cut out cards** along the box borders

### Better Quality Method:

1. **Convert markdown to PDF**:
   - Use a markdown viewer with print function
   - Or paste into a document editor and save as PDF
2. **Print on cardstock** (110-220 gsm)
3. **Cut precisely** with a paper cutter
4. **Optional**: Insert into card sleeves with a playing card for rigidity

### Professional Method:

1. **Export to PDF** preserving formatting
2. **Take to print shop** for cardstock printing
3. **Request cutting** along card borders
4. **Optional**: Request lamination or rounded corners

## Assembly Instructions

### Step 1: Print All Pages
Print all 15 pages from the 5 card files:
- 1 page of Ontology cards
- 2 pages of Epistemology cards
- 3 pages of Theory/Framework cards
- 6 pages of Method cards
- 3 pages of Object-of-Study & Event cards

### Step 2: Cut Out Cards
- Use scissors or paper cutter
- Cut along the outer borders of each card box (┌─┐ └─┘)
- Take care with Method cards - they're compact!
- You should have **116 cards** total when done

### Step 3 (Optional): Reinforce Cards
Choose one method:

**Option A - Card Sleeves**:
1. Purchase 120 standard poker-size card sleeves (63.5mm × 88mm)
2. Insert each card into a sleeve
3. Optional: Add a playing card behind each for rigidity

**Option B - Cardstock Backing**:
1. Cut cardstock to match each card size
2. Glue printed card to cardstock using glue stick
3. Allow to dry fully before use

**Option C - Lamination**:
1. Arrange cards on laminating sheets (leave space between)
2. Laminate following your machine's instructions
3. Cut out individual cards after laminating

### Step 4: Organize Deck
Organize cards into piles by type:
- **Ontology** (3 cards) - Set aside 1 for first player
- **Epistemology** (10 cards) - Set aside 1 for first player
- **Theory/Framework** (21 cards) - Shuffle into main deck
- **Method** (47 cards) - Shuffle into main deck
- **Object-of-Study** (20 cards) - Set aside, reveal 1 at game start
- **Event** (15 cards) - Shuffle into main deck

**Main Draw Deck**: 83 cards (21 Theory + 47 Method + 15 Event)

## Tips for Best Results

### Readability:
- **Method cards are compact** - if text is too small, print at 110-120% scale
- Use a **monospace font** (Courier, Consolas, Monaco) for best box alignment
- Ensure your **text editor doesn't wrap lines** when viewing markdown files

### Durability:
- **Lamination** provides best durability for frequent play
- **Card sleeves** allow easy updates (swap in new card versions)
- **Cardstock alone** is sufficient for light use

### Organization:
- Use **rubber bands or deck boxes** to store card types separately
- Keep **Ontology/Epistemology separate** from main deck (they're dealt differently)
- Consider **color-coding** card backs by type (if making multiple copies)

---

## Troubleshooting

### "Cards don't fit on the page"
- Ensure printing at **100% scale** (not "fit to page")
- Check that margins are set to **0.5" or less**
- Try **landscape orientation** if needed

### "Text is too small to read"
- Method cards are intentionally compact
- Print at **110-120% scale** if needed
- Use **thicker/darker font** in your editor before printing

### "Boxes are misaligned"
- Use a **monospace font** (all characters same width)
- Ensure editor is **not wrapping lines**
- Copy exact text without reformatting

### "I need more copies of certain cards"
- Print additional copies of specific pages
- Most useful: Extra **Object-of-Study cards** (for variety between games)
