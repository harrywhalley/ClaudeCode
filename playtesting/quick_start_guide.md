# Methodology Match: Playtesting Quick Start Guide

**Want to start playtesting right away? Follow these steps!**

---

## Option 1: Fastest - Online Digital Playtest (30 minutes setup)

### Step 1: Create Digital Cards (Use PlayingCards.io)

1. **Go to**: https://playingcards.io/
2. **Create a room** (no account needed)
3. **Upload cards**:
   - Use the CSV to create simple text-based cards
   - Or use provided card images (if available)
   - Quick method: Create 116 cards with just titles and key info

### Step 2: Setup the Game Table

**Create these areas in the virtual space**:
- Draw Pile (face-down)
- Discard Pile (face-up)
- Object-of-Study card (center, revealed)
- 4 Player areas with:
  - Hand area (7 cards)
  - Research Stack 1 area
  - Research Stack 2 area
  - Secret Ontology card (face-down)

### Step 3: Prepare the Deck

1. **Separate 3 Ontology cards** - set aside
2. **Separate 20 Object-of-Study cards** - set aside
3. **Shuffle remaining cards** (Epistemology + Theory + Method + Event = 93 cards)
4. **Deal to each player**:
   - 1 secret Ontology (face-down)
   - 7 cards from main deck
5. **Place 1 Object-of-Study** in center (revealed)
6. **Form draw pile** with remaining deck

### Step 4: Share Link & Play!

- Share room link with 2-3 other players
- Reference the rulebook (rules_v1.md)
- Start playing!
- Take notes using session_log_template.md

**Time**: ~30 min setup, ~45-60 min gameplay

## Option 2: Simple - Print & Play (2 hours setup)

### Step 1: Create Printable Cards

**Quick & Dirty Method**:
1. Open `Methodology_Match_cards_02.csv` in spreadsheet
2. Format for printing:
   - Card title (large font)
   - Card type (small font)
   - Key info only (synergies, scores)
   - For Methods: abbreviated description
3. Print 9 cards per page on cardstock
4. Cut out cards

**Better Method** (if you have design skills):
1. Create card template in Canva/Figma/PowerPoint
2. Import CSV data
3. Generate printable PDFs
4. Print on cardstock

### Step 2: Prepare Physical Components

**Materials needed**:
- 116 printed cards
- Scissors or paper cutter
- Optional: card sleeves (63.5mm × 88mm / poker size)
- Score sheet (printed)
- Pencils

### Step 3: Organize the Deck

Same as digital version:
1. Separate Ontology cards
2. Separate Object-of-Study cards
3. Shuffle main deck
4. Deal and setup

### Step 4: Play!

- Reference rulebook
- Use session log template for notes
- Collect feedback forms after

**Time**: ~2 hours setup (first time), ~45-60 min gameplay

## Option 3: Quick Test - Solo "Dummy" Game (1 hour)

**Purpose**: Validate rules work before bringing in other players

### Setup
- Play as all 4 players yourself
- Make random decisions
- Focus on rules verification not strategy

### What to Check
- [ ] Can I complete the setup correctly?
- [ ] Does turn structure make sense?
- [ ] Can I build valid stacks?
- [ ] Can I calculate scores correctly?
- [ ] Are there any impossible situations?
- [ ] Do all the rules work together?

### Document
- Any confusing rules
- Scoring difficulties
- Impossible situations
- Time to complete

**Time**: ~1 hour total

## Recommended First Playtest Approach

### Hybrid Quick Start (Best for first test):

**Day 1** (1 hour):
1. Do Solo "Dummy" Game
2. Fix any obvious rule issues
3. Create simple digital prototype

**Day 2** (2 hours):
1. Playtest digitally with 2-3 people
2. Use session log template
3. Collect feedback
4. Log issues

**Day 3** (1 hour):
1. Review feedback
2. Make first round of changes
3. Update cards/rules

**Day 4** (2 hours):
1. Second playtest with changes

3. Iterate

## Quick Reference: What to Track

During gameplay, observe:
- **Confusion points** (when/why players ask questions)
- **Stuck points** (when players can't make progress)
- **Fun points** (when players seem engaged/excited)
- **Balance issues** (cards that seem too strong/weak)
- **Time spent** (turns, decisions, full game)

After gameplay, collect:
- Final scores (all players)
- Feedback forms
- Rule questions that arose
- Suggested changes
- General reactions

## What Success Looks Like

**Minimal Success** (first playtest):
- Game completes without breaking
- Players understand basic goal
- Some enjoyment despite issues
- Clear list of what to fix

**Good Success** (later playtests):
- Game flows smoothly
- Players strategize
- Few rules questions
- Players want to play again

**Excellent Success** (near final):
- No rules confusion
- Balanced and engaging
- Educational value clear
- Players enthusiastically recommend

## Common First-Time Issues (Don't Panic!)

**"The game took 2 hours!"**
→ Normal for first playtest. Will speed up with familiarity.

**"Players were constantly confused!"**
→ Expected. Take notes on *what* confused them. Fix those rules.

**"One player dominated completely!"**
→ Good data! Figure out why. Balance issue or luck?

**"Nobody read the Method descriptions!"**
→ Interesting! Ask why. Too small? Not relevant to gameplay?

**"Players kept asking the same questions!"**
→ That rule needs clarification or an example in rulebook.

## After Your First Playtest

1. **Celebrate!** You did it! 🎉
2. **Don't change everything at once** - prioritize top 3 issues
3. **Document everything** - future you will thank you
4. **Test changes** - don't assume fixes work without testing
5. **Iterate quickly** - test again within a few days while fresh

## Need Help?

Common questions and solutions:

**Q: I don't have 4 players**
A: Start with 2-player tests. They're faster and easier to schedule.

**Q: I'm not a designer, how do I make cards?**
A: Start with text-only! Functionality first, aesthetics later.

**Q: Remote playtesting tips?**
A: Use PlayingCards.io + Zoom. Share screen, use breakout rooms for secret Ontologies.

**Q: How many playtests before it's "done"?**
A: Minimum 10 sessions. Stop when no new issues emerge and feedback is consistently positive.
