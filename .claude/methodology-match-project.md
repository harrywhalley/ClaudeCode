# Methodology Match: Project Context

## Project Overview

Methodology Match is a physical card game designed to help PhD students in arts and humanities understand research methodologies and how different methodological components connect together.

### Core Concept
Players build coherent "Research Stacks" by aligning:
- **Ontologies**: Fundamental beliefs about the nature of reality
- **Epistemologies**: Theories of knowledge and how we can know things
- **Theories/Frameworks**: Theoretical lenses for interpreting research
- **Methods**: Specific research techniques and approaches
- **Objects-of-Study**: Research topics/subjects

### Educational Purpose
The game teaches players:
- How different methodological components relate to each other
- Which combinations are coherent vs. incompatible
- The strengths and limitations of different research approaches
- Real-world considerations (ethics, reproducibility, novelty, sensibility)

## Game Components

### Card Types & Quantities
1. **Ontology Cards** (3 cards)
   - Realism/Objectivism
   - Relativism/Constructivism
   - Critical Realism (or similar middle ground)

2. **Epistemology Cards** (9 cards)
   - Examples: Positivist, Interpretivist, Critical, Feminist, Poststructuralist, etc.

3. **Theory/Framework Cards** (20 cards)
   - Each has 1-3 epistemological alignments
   - Tiered point values based on specialization

4. **Method Cards** (47 cards)
   - Each has multiple attributes:
     - Reproducibility score (1-10)
     - Sensibility score (1-10)
     - Novelty score (1-10)
     - Ethical Risk rating (1-10)
     - Epistemological synergies
   - Examples: Semi-structured interviews, Surveys, Ethnography, Discourse analysis, etc.

5. **Object-of-Study Cards** (20 cards)
   - Shared research topic for all players in a game

6. **Event Cards** (15 cards)
   - Special effects that simulate academic life challenges/opportunities

**Total: 114 cards**

## Key Design Principles

### 1. Academic Accuracy
- All methodological connections must be grounded in research methods literature
- Card descriptions should reflect real-world usage and considerations
- Compatibility/incompatibility must be defensible from scholarly perspectives

### 2. Educational Value
- Cards should teach while playing
- Text should include:
  - Brief method/theory descriptions
  - Pros and cons
  - Typical use cases
  - Key considerations (ethical, practical, theoretical)

### 3. Game Balance
- Point values should encourage both:
  - Methodologically sound research (paradigm coherence)
  - Strategic diversity (different paths to victory)
- Extreme methods (very low Reproducibility or Sensibility) have additional costs

### 4. Clarity and Consistency
- Terminology must be consistent across all cards
- Formatting should be uniform
- Synergies and alignments clearly marked

## Card Content Requirements

### Method Cards Should Include:
- **Name**: Clear, recognizable method name
- **Brief Description**: 1-2 sentences explaining what it is
- **Pros**: 2-3 key advantages
- **Cons**: 2-3 key limitations or challenges
- **Epistemological Synergies**: Which epistemologies it aligns with
- **Scores**:
  - Reproducibility (how replicable/systematic)
  - Sensibility (depth of understanding/interpretation)
  - Novelty (how cutting-edge/emerging)
  - Ethical Risk (potential ethical concerns)

### Epistemology Cards Should Include:
- **Name**: Standard terminology from research methods literature
- **Core Belief**: What this epistemology assumes about knowledge
- **Compatible Ontologies**: Which ontological positions align
- **Incompatible Ontologies**: Which create tension
- **Key Characteristics**: Brief overview of approach

### Theory/Framework Cards Should Include:
- **Name**: Recognized theoretical framework
- **Brief Description**: Core concepts and purpose
- **Epistemological Alignments**: Which epistemologies it fits with (1-3)
- **Key Thinkers**: Optional - major scholars associated
- **Application Areas**: Typical research contexts

## Quality Control Checklist

When reviewing or creating cards:
- [ ] Is the terminology consistent with research methods literature?
- [ ] Are the synergies/alignments defensible?
- [ ] Is the text clear and educational?
- [ ] Are scores appropriate and balanced?
- [ ] Does it fit with the existing card ecosystem?
- [ ] Would a PhD student learn something valuable from this card?

## Testing Goals

### Online Playtesting
- Test game mechanics and flow
- Validate point balance
- Check if methodological teaching goals are met
- Identify confusing rules or card interactions

### Production Goals
- Create print-ready card templates
- Establish consistent visual design
- Ensure cards are readable and attractive
- Consider accessibility (text size, color contrast, etc.)

## Project Workflow

1. **Review Phase**: Audit all existing cards for consistency and accuracy
2. **Enhancement Phase**: Improve card text with literature-based content
3. **Balance Phase**: Adjust scores and point values based on gameplay
4. **Testing Phase**: Playtest online version, gather feedback
5. **Refinement Phase**: Iterate based on testing results
6. **Production Phase**: Create final templates for physical printing

- Ethical guidelines for research

## Notes for AI Assistant

- Maintain academic rigor while keeping content accessible

- Flag any methodological claims that need verification
