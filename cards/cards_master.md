This file contains all cards for the Methodology Match game. The structure is designed for easy editing by both humans and LLMs.

## Ontology Cards

### Realism
**Type:** Ontology
**Description:** Realism says the world has a stable structure that exists whether or not we observe it.
**Gameplay Effect:** +2 points when using causal or quantitative methods.

### Relativism
**Type:** Ontology
**Description:** Relativism argues that what we call 'reality' changes with culture, language, and history.
**Gameplay Effect:** May hold contradictory findings and blocks generalisation bonuses from Realist players.

### Constructivism
**Type:** Ontology
**Description:** Constructivism sees reality as something people build together through conversation, symbols, and shared practice.
**Gameplay Effect:** Draw one extra Method after completing a qualitative stack.

## Card Editing Guide for LLMs

### Structure Rules
1. Each card type has its own section with `## Card Type` heading
2. Individual cards use `### Card Name` heading
3. All attributes use `**Attribute Name:** value` format
4. Blank line between each card for readability
5. Cards within a type are listed alphabetically

### Common Fields by Card Type

**Ontology Cards:**
- Type, Description, Gameplay Effect

**Epistemology Cards:**
- Type, Compatible Ontology, Incompatible Ontology (optional), Incompatible Methods (optional), Synergy

**Theory/Framework Cards:**
- Type, Alignment, Points Bonus, Scoring Rule

**Method Cards:**
- Type, Alignment, Ethical Risk (1-9), Reproducibility (1-9), Sensibility (1-9), Novelty (1-9)

**Object-of-Study Cards:**
- Type, Description, Keywords (optional, to be added)

**Event Cards:**
- Type, Effect

### Adding New Cards
1. Find the appropriate `## Card Type` section
2. Copy the structure of an existing card in that section
3. Create new `### Card Name` heading in alphabetical position
4. Fill in all required fields using `**Field:** value` format
5. Update the card count at the top of the file

### Editing Existing Cards
1. Search for `### Card Name` to locate the card
2. Update the specific `**Field:** value` line(s)
3. Maintain consistent formatting

### Deleting Cards
1. Remove entire card section from `### Card Name` to blank line before next card
2. Update the card count at the top of the file
